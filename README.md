# Автоматизация тестирования API веб-сервиса «Stellar Burgers»

Этот проект представляет собой пакет автономных API-тестов для проверки ключевых бизнес-сценариев и корректности работы бэкенда сервиса «Stellar Burgers».

## Описание проекта

Тесты написаны на Python с использованием фреймворка **Pytest** и библиотеки **Requests** для отправки HTTP-запросов. Для генерации реалистичных данных используется библиотека **Faker**.

**Особенности архитектуры реализации:**
* **Изоляция конфигурации и констант:** Все базовые URL, эндпоинты ручек и ожидаемые текстовые сообщения ответов сервера вынесены в отдельные классы `Urls` и `ResponseMessages` внутри файла `config.py`.
* **Генерация данных:** Логика создания уникальных учетных данных пользователя (email, пароль, имя) инкапсулирована в отдельный модуль-генератор `generators.py`.
* **Автоматическое управление фикстурами:** Подготовка тестовой среды (регистрация пользователя, сквозная авторизация, получение хешей ингредиентов) и очистка базы данных (удаление созданных пользователей после завершения теста) реализованы в `conftest.py` через цепочки вызовов и блоки `yield`.


**Проект покрывает следующие функциональные блоки:**
* **Создание пользователя (`POST /api/auth/register`):** Успешная регистрация уникального пользователя, валидация кодов ошибок при попытке создания дубликата и при отправке пустых обязательных полей (`email`, `password`, `name`).
* **Логин пользователя (`POST /api/auth/login`):** Проверка успешной авторизации с возвратом токена `accessToken`, обработка негативных сценариев при отправке некорректных учетных данных (неверный email/пароль).
* **Создание заказа (`POST /api/orders`):** Проверка создания заказа авторизованным пользователем (с передачей токена в заголовках) и неавторизованным пользователем. Тестирование логики с передачей валидного списка ингредиентов, пустого списка и некорректного хеша ингредиентов (обработка ошибки 500). 

## Как установить проект

1. Клонируйте репозиторий с проектом или распакуйте архив в рабочую папку.
2. Откройте терминал в папке проекта, активируйте виртуальное окружение и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Как запустить автотесты

Вы можете запустить весь пакет тестов целиком или каждый модуль по отдельности с помощью консольных команд.

* **Запуск абсолютно всех тестов проекта:**
  ```bash
  pytest tests/
  ```
* **Запуск конкретного модуля:**
  * Проверка создания пользователя: `pytest tests/test_create_user.py`
  * Проверка авторизации пользователя: `pytest tests/test_login_user.py`
  * Проверка оформления заказа: `pytest tests/test_create_order.py`

## Генерация отчётов

Интерактивные графические отчёты по результатам прогона тестов формируются с помощью плагина **Allure**.

* **Просмотр отчёта через локальный сервер:**
  ```bash
  allure serve allure-results
  ```
